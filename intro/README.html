Lab intro - Comment une application se fait-elle compromettre ?

Lab volontairement vulnérable (PHP/Apache). Il contient une injection SQL, un stockage de mots de passe en clair, un upload non restreint et une RCE, par conception. À lancer en local, réseau isolé, jamais exposé sur internet. Données et identifiants factices (corp.lab).

À quoi ça sert

L'introduction du cours. Avant de parler défense et CI/CD, l'étudiant voit une compromission de bout en bout : d'un champ de login jusqu'à l'exécution de commandes sur le serveur. Chaîne :

SQL injection → récupération du compte admin → upload d'un webshell (contournement de filtre) → RCE

Démarrer

Linux / macOS / Git Bash

docker compose -f docker-compose.local.yml up -d --build
# -> http://localhost:8080
./reset.sh      # remettre a zero (efface le webshell depose)

Windows (cmd.exe)

docker compose -f docker-compose.local.yml up -d --build
reset.bat

Prérequis : Docker Desktop. Rien d'autre (PHP tourne dans le conteneur).

Contenu

  • cible/ - l'application vulnérable (PHP + Apache).
  • enonce/enonce-etudiant.html - le TP guidé pas à pas.
